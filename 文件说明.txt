一、本文件夹里有什么
--------------------
README.md
    使用说明。项目简介、环境要求、快速开始、界面四大区对照、AI 三种模式配置、
    提示词设置、抓取模式、目录结构、常见问题与免责声明。

docs\技术选型与架构方案.md
    技术选型与架构方案文档，说明工具的设计思路、技术方案与使用局限。

bsr_monitor.py
    工具主程序。单文件形式，内含网页界面、抓取、分析与导出逻辑。
    AI 分析报告与运营建议的提示词可在界面 ⑤ 设置 →「提示词设置」中查看和编辑，
    顶部「生成 AI 分析」按钮可用当前提示词基于最近快照重新生成报告。
    运行它即启动工具，不要重命名、不要删除。

run.bat
    启动脚本。双击它即可运行工具。
    它会先读取 python_local.txt 里记录的 Python 路径；若该文件不存在，
    则自动依次尝试系统 PATH 中的 python 与 py -3 启动。

build_exe.bat
    打包脚本。把工具打包成免安装的 BSRMonitor.exe（需要已安装 Python 与 pyinstaller）。
    打包结果在 dist\BSRMonitor.exe，可分发给没有 Python 环境的用户。

install_scroll_deps.bat
    依赖安装脚本。安装"浏览器滚动抓满 TOP100"所需的 playwright 组件
    （复用本机已装的 Edge/Chrome，不会另外下载浏览器内核）。
    只需运行一次；不安装也不影响 HTTP 直抓，只是抓取数量较少（最多约 60 款）。

python_local.txt
    本机 Python 路径记录，内容只有一行完整路径。
    仅供本机使用，属于机器专属文件，不要分发给他人（.gitignore 已排除）。

requirements_optional.txt
    可选增强依赖清单（pyinstaller、playwright、requests、beautifulsoup4）。
    日常 HTTP 直抓与离线分析不需要安装本文件里的依赖。

.gitignore
    版本库忽略清单：排除 python_local.txt、data/config.json 与全部运行时数据
    （快照/变动/报告/导出/原始页面）、__pycache__、*.pyc、*.log、打包产物。

文件说明.txt
    本说明文件。

data\  （目录）
    运行时数据目录，存放配置、抓取快照、报告与导出文件。
    由程序首次运行时自动创建（含 snapshots / changes / reports / exports / raw 子目录）；
    其中 config.json 在界面 ⑤ 设置中点「保存」后生成，缺失时程序以内置默认配置启动。
    目录与配置项的详细说明见 README.md「八、目录结构」。

__pycache__\  （目录）
    Python 自动生成的字节码缓存目录，可忽略，也可随时删除，
    程序下次运行会自动重建（.gitignore 已排除，不会入库）。

二、如何运行
------------
1. 确认电脑已安装 Python 3.10 或更高版本（安装时勾选 Add python.exe to PATH）。
2. 双击 run.bat。
3. 程序启动后会在窗口里显示本机访问地址（默认端口 8965），
   浏览器会自动打开该地址；若没打开，手动访问即可。
4. 若希望抓满 TOP100（而不是 HTTP 直抓的约 60 款），
   请先运行一次 install_scroll_deps.bat。

三、关于配置与首次运行
----------------------
1. 本工具不强制要求配置文件：data\config.json 缺失时，程序以内置默认配置
   （离线模板模式，ai_mode=offline）直接启动，不会自动生成该文件；
   在界面 ⑤ 设置中点「保存」之后才会写入 data\config.json。
2. 目标店铺信息（店铺名称 / 关键词 / 店铺主页 marker）在 ⑤ 设置 →「店铺设置」中填写，
   保存后立即生效；未设置时看板显示"未设置目标店铺"，不影响抓取与导出。
3. AI 模型在 ⑤ 设置 →「AI 模型配置」中三选一：离线模板 / 本地 Ollama / OpenAI 兼容 API。
   API Key 只保存在本机 data\config.json，不会上传。

四、分发给他人之前请注意
------------------------
1. 请先删除 python_local.txt。
   它记录的是本机专属 Python 路径，别人电脑上没有这个路径，
   留着会让人误以为缺少文件，也会影响启动判断。
2. 可以一并删除 __pycache__ 目录（会自动重建）。
3. data\config.json 中保存着本机的店铺名称、店铺关键词、店铺主页 marker 与 AI 配置，
   若要分发给他人，建议先删除整个 data\ 目录（程序启动时会自动重建各子目录）；
   缺少 config.json 不影响运行，对方在界面保存设置后会生成自己的配置。
4. data\ 下运行时产生的数据文件（快照、变动、报告、导出等）也建议一并清空，
   保持"刚下载"的干净状态。
5. 不要分发 dist\、build\、*.spec 等构建产物与 temp\ 等临时目录。
